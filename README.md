# Dannote 요약 
**DanNote**는 React + Vite + Tailwind CSS + DaisyUI 기반의  
문서 요약 및 용어 검색 기능을 제공하는 웹 애플리케이션입니다.

---

## 주요 기능

- **회원가입 / 로그인 (localStorage 기반)**
- **텍스트 요약 입력 + 실행**
- **파일 업로드 및 Drag & Drop 예정**
- **요약 히스토리 저장 / 삭제 / 중요 표시**
- **다크모드 & 테마 토글 (DaisyUI 활용)**
- **용어 검색 기능 준비 중**
- 📦 Vite 기반 빠른 HMR 개발 환경

---
## 적용

- React + Vite
- Tailwind CSS + DaisyUI
- localStorage 기반 데이터 저장
- (예정) Flask 백엔드 연동
